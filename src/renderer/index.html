Any CLI that speaks MCP can drive a pane

OnColourNameCommand

Placeholders in a command:

{url}this pane's MCP endpoint, for CLIs that take a server URL on the command line
{mcpConfig}path to a generated mcp.json ({"mcpServers":{"wb":{"type":"http","url":…}}})
{prompt}the task as one argument. Leave it out and the task goes in through stdin.

CLIs that only read MCP servers from their own settings need the pane registered once, as Antigravity does: agy mcp add wb http://127.0.0.1:7788/mcp/agy. The pane URL is always /mcp/<id>, where the id is the name in lower case.
