Agents

Any CLI that speaks MCP can drive a pane

OnColourNameCommand (first question) / Follow-up command

Placeholders in a command:

{url}this pane's MCP endpoint, for CLIs that take a server URL on the command line
{mcpConfig}path to a generated mcp.json ({"mcpServers":{"wb":{"type":"http","url":…}}})
{prompt}the task as one argument. Leave it out and the task goes in through stdin.
{session}a UUID made for each new task. Put it in both commands so the follow-up resumes the same session (claude --session-id / --resume).

The follow-up command is optional. Without one, the earlier answer is pasted into the next prompt instead of resuming. CLIs that only read MCP servers from their own settings need the pane registered once, as Antigravity does: agy mcp add wb http://127.0.0.1:7788/mcp/agy. The pane URL is always /mcp/<id>, where the id is the name in lower case.
