# v0.3 report — 2026-11-23

Branch: `feat/v0.3-real-users`. Implementation is present, but the requested completion criteria are **not met**: no local commits or DMG could be created in this execution environment.

## Changes by item

1. **Sign-in hand-off.** Added `ask_user_to_sign_in(reason)`, a banner above the interactive browser, Done/Skip responses, a ten-minute timeout, cancellation on stop/exit, and a distinct pane/status-bar state. The unchecked persistence option switches a clean pane to My logins before sign-in. Browser tools pause during the hand-off; password values are omitted from element labels. The agent guide now requests manual sign-in and still forbids passwords/payment details. Codex and Claude receive longer tool timeouts, including existing Codex command entries.
2. **Setup.** Added first-run Setup and a toolbar button. Enabled CLIs are checked on PATH with a five-second version timeout; unavailable CLIs are excluded from runs. Missing installations show the requested commands or Antigravity's [official docs](https://antigravity.google/docs/getting-started?tab=cli) with an unverified-command label. `agy mcp list` is checked when supported, and registration runs only after the button click. Users are instructed to sign the CLIs in from a terminal. Common macOS CLI directories are added for Finder launches.
3. **Korean UI.** Added a dependency-free ko/en dictionary for renderer UI, defaulting from `app.getLocale()`. Setup contains a persisted language selector. Live hand-off labels, status, profiles, comparison, history and export copy are translated.
4. **Starter tasks.** Added four translated chips below the task bar. They fill the prompt and clear follow-up mode without starting a run.
5. **macOS build.** `npm run dist:mac` uses the installed arm64 Electron, wraps the existing icon as ICNS, packages an unsigned app and invokes native `hdiutil` for a DMG. README documents unsigned-app installation. The app package succeeded; DMG creation failed. x64 was omitted because it requires another Electron download.
6. **README/version.** Added First run, the hand-off tool and workflow, setup/language guidance, revised smoke commands and honest platform-validation status. Updated `package.json` and root lockfile metadata to `0.3.0`.
